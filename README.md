# SmartHR

### AI-Assisted HR Policy Assistance and Employee Query Management System

SmartHR is a web-based application developed using Python and Flask to simplify employee access to HR policies and automate employee query handling using Generative AI.

The system uses document retrieval techniques and Google's Gemini API to generate responses based on relevant HR policy information.

## Features

* Employee and HR role-based access.
* HR policy document management.
* Document processing and text extraction.
* Intelligent retrieval of relevant policy information.
* AI-powered employee query responses.
* Employee query tracking and management.
* Query escalation functionality.

## Technologies Used

* Python
* Flask
* Flask-SQLAlchemy
* SQLite
* HTML
* CSS
* JavaScript
* Google Gemini API

## Application Modules

* Authentication Module
* Employee Module
* HR Management Module
* Employee Query Management Module
* Document Processing Module
* AI Response Generation Module
